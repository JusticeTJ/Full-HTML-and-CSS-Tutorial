# HTML and CSS Learning Project

This folder contains practice work from learning the basics of building web pages with HTML and CSS. It is a collection of small examples and exercises rather than one finished website. The files show how web pages are structured, styled, and given common features such as forms, tables, navigation, images, audio, and video.

## Project contents

- **`public/`** — HTML pages and exercises. Some examples include `index.html`, `aboutmyself.html`, `forms.html`, `tables.html`, `nav.html`, and `z-index.html`.
- **`css/`** — Stylesheets used by the HTML exercises, including examples for text, colours, navigation, forms, and positioning.
- **`image/`** — Images used in some of the pages.
- **`Audio/`** — Audio used by the media example.
- **`video/`** — Video used by the media example.
- **`js/`** — A folder for JavaScript practice; it may be empty for now.

## Topics covered

The examples explore:

- Basic HTML page structure, headings, paragraphs, links, and lists
- CSS colours, text styling, and page layout
- Navigation bars and positioning with `z-index`
- Forms, tables, and simple login or sign-up page layouts
- Adding images, audio, and video to a page

The pages are learning exercises, so some content, spelling, and styling may be unfinished or inconsistent. That is part of the project's role as a place to practise and improve.

## View the pages

1. Open this folder in a code editor such as Visual Studio Code.
2. Start a local web server for the folder. In Visual Studio Code, you can use the **Live Server** extension if it is installed.
3. Open a page from the `public/` folder, such as `index.html`, `cssnote1.html`, or `forms.html`.

Using a local server is recommended because some pages refer to images, audio, and video using paths from the project root. There is no build step or package installation required.
